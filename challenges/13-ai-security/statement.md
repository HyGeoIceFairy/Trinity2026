# angel

死后世界的学校里，战线又有了一项新作战。

学生会的记录系统把一张旧照片归进了 NPC 档案。由理想把它改成战线成员的记录，但修补痕迹必须足够小，连整张照片的总亮度都不能改变。

提交一份照片数据，让系统将它判为 `SSS`：最多修改 **12** 个像素，每个像素最多增减 **8**，所有像素的总和保持不变。像素必须是 0—255 的整数，顺序为从上到下、从左到右。提交 JSON 格式为 `{"pixels": [256 个像素值]}`。

附件包含原始照片数据、模型与本地检查程序；Python 3.9 以上即可运行。将提交数据保存为 UTF-8 JSON 文件，在解压目录运行 `python evaluate.py sample.json` 可先做本地检查，再到实例页面上传文件或粘贴数据。实例中通过检查后会显示 Flag。
